# v3.1

Clanker v3.1 deploys tokens into Uniswap v3 pools with single-sided liquidity, an optional creator buy and an optional time-locked vault.

## Core contracts

Clanker v3.1 consists of five main contracts:

1. [**ClankerToken**](clankertoken-v3.1.0-and-v4.0.0.md): A Superchain-compatible ERC20 contract.
2. [**Clanker**](v3.1/clanker-direct-contract-deployments.md): The primary contract. It handles token deployment, Uniswap v3 pool creation, and single-sided liquidity position placement. Users can optionally make an initial swap and deposit a portion of the token supply into a time-locked vault.
3. **ClankerDeployer**: A helper library that reduces the code size of the Clanker contract.
4. [**ClankerVault**](v3.1/clankervault.md): Lets creators manage and collect their locked tokens.
5. [**LpLockerv2**](v3.1/lplockerv2.md): Lets creators manage and collect their portion of the trading fees generated by their token's pool. The Clanker team also uses it to collect its portion of the trading fees.

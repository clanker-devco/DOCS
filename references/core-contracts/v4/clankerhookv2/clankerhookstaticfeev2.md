# ClankerHookStaticFeeV2

**ClankerHookStaticFeeV2** applies a fixed fee to the deployed token and the paired token, built on **ClankerHookV2**.

It works the same as **ClankerHookStaticFee**, except that it inherits from **ClankerHookV2** instead of **ClankerHook**. See the [**ClankerHookStaticFee**](../clankerhook/clankerhookstaticfee.md) page for details.

Clanker is a token deployment protocol on Base, Arbitrum, and other EVM chains. These docs cover token deployments, Droids, the API, the SDK and the protocol's contracts.

You can launch a token from [clanker.world](https://www.clanker.world), by tagging @clanker on Farcaster, through the API, or with the SDK. Each token launches with its own liquidity pool, and the fees or tax from trading flow back to the creator as rewards.

## Clanker v5

Clanker v5 is the current version of Clanker, live on Base. A v5 token charges a buy and sell tax on every trade instead of an LP fee. The tax pays the creator's rewards and can also fund holder dividends, a burn and an integrator share.

You can launch a v5 token on clanker.world or with the [deploy API](/general/token-deployments/v5-deployments). The [v5 contracts](/references/core-contracts/v5) page covers the contracts, launch policy and permissions.

## API Reference

The Clanker REST API is available at `https://www.clanker.world/api`.

| Auth method     | Header                          | Description                            |
| --------------- | ------------------------------- | -------------------------------------- |
| Public          | None                            | No authentication required             |
| Partner API key | `x-api-key: <key>`              | Issued per partner by the Clanker team |
| User auth       | `Authorization: Bearer <token>` | Farcaster or Privy authentication      |

- [Public API](/api-reference/public): token search, trending, users, presales, airdrops and market data.
- [Authenticated API](/api-reference/authenticated): partner endpoints for tokens, deployment and fees.
- [User API](/api-reference/user): Preclank management and saved tokens.

## SDK Reference

The [clanker-sdk](https://www.npmjs.com/package/clanker-sdk) is a TypeScript library for deploying and managing Clanker tokens on-chain. It covers v4 tokens today, and v5 support is coming soon. To launch a v5 token now, use clanker.world or the [deploy API](/general/token-deployments/v5-deployments).

```bash
npm install clanker-sdk
```

- [Core Utilities](/sdk-reference/core-utilities): types, constants, vanity addresses and Merkle tree helpers.
- [V4 Clanker Class](/sdk-reference/v4): deploy tokens, claim rewards and update metadata.
- [V3 Clanker Class](/sdk-reference/v3): v3 token deployment and management.
- [V4 Extensions](/sdk-reference/extensions): airdrops, presales and allowlist management.
- [Legacy Fee Claims](/sdk-reference/legacyfeeclaims): fee claims for v0 to v3.1 tokens.

## Contributing

The API and SDK sections are generated from source code:

- **API docs** come from [`clanker.world/docs/api-registry.ts`](https://github.com/clanker-devco/clanker.world/blob/main/docs/api-registry.ts). Update the registry to change the API documentation.
- **SDK docs** are generated with [TypeDoc](https://typedoc.org/) from JSDoc comments in [`clanker-sdk/src/`](https://github.com/clanker-devco/clanker-sdk/tree/main/src). Update the JSDoc in source to change the SDK documentation.

Both repos have GitHub Actions that regenerate the docs and push them here on every merge to `main`.

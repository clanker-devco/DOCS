title: "ClankerMevDescendingFees"
---

**ClankerMevDescendingFees** is a MEV module that charges snipers higher fees by starting the LP fee high and lowering it over a short period after launch.

## How it works

Deployers specify a starting LP fee (up to 80%), an ending fee and a time to descend (up to 2 minutes). Clanker's original recommended configuration starts effective fees at 80% and descends to 5% over 30 seconds, after which the pool's normal fee behavior starts. The clanker.world form's default is 80% to 5% over 15 seconds. For the reasoning behind these choices, see the Clanker [v4 sniper activity writeup](https://paragraph.com/@clankerworld/clanker-v4_1-sniper-tech).

The fee decays following the formula `fee = endingFee + feeRange * (timeDecay / timeToDecay)²`.

Swaps can start in the second after deployment.

![mev descending fees 1](/assets/mev-descending-fees-1.png)

The fee applied to a swap is the LP fee plus Clanker's additional 20% fee. Clanker's default starting market cap is 10 WETH (about $40k when written), so with the proposed starting fee of 80%, snipers start at an effective market cap of about $200k.

![mev descending fees 2](/assets/mev-descending-fees-2.png)

## Initialization

Token deployers configure the fee parameters with this struct:

```solidity
struct FeeConfig {
    uint24 startingFee; // LP fee to start at
    uint24 endingFee; // LP fee to descend to
    uint256 secondsToDecay; // seconds to decay over
}
```

Set this config on the deployment struct as follows:

```solidity
address clankerMevDescendingFees; // address of the deployed MEV module
IClanker.DeploymentConfig memory deploymentConfig;

// setup the MEV module data
IClankerMevDescendingFees.FeeConfig memory feeConfig = IClankerMevDescendingFees.FeeConfig({
    startingFee: 666777, // 66%, 80% applied fee
    endingFee: 50000, // 5%
    secondsToDecay: 30 // 30 seconds
});

deploymentConfig.mevModuleConfig.mevModule = address(clankerMevDescendingFees);
deploymentConfig.mevModuleConfig.mevModuleData = abi.encode(feeConfig);
```

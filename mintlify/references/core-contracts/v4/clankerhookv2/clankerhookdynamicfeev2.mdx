---
title: "ClankerHookDynamicFeeV2"
---

**ClankerHookDynamicFeeV2** applies a volatility-based dynamic fee, built on **ClankerHookV2**.

It works the same as **ClankerHookDynamicFee**, except that it inherits from **ClankerHookV2** instead of **ClankerHook**. See the [**ClankerHookDynamicFee**](/references/core-contracts/v4/clankerhook/clankerhookdynamicfee) page for details.

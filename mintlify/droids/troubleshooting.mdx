## Common errors

| Symptom                                                                   | Cause                                                                                            | Fix                                                                                                                               |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `Launcher signature headers are required`                                 | The action must be signed by the wallet you launched from.                                       | Connect that wallet and sign again.                                                                                               |
| `Droid-first token launch requires Base mainnet with native USDC pairing` | You're not on Base mainnet, or the paired token isn't USDC.                                      | Switch to Base and choose USDC as the paired token.                                                                               |
| The chat says the droid needs USDC.                                       | The droid's runtime wallet is empty, so inference fails with `Insufficient USDC runway`.         | Send USDC on Base to the wallet address shown in the Droid panel.                                                                 |
| Status is **Needs attention** or runway shows 0 days.                     | The balance is low or empty, or the last scheduler tick failed.                                  | Top up with USDC on Base. If runway is healthy and the status still shows, the runtime link may be stale: wait for the next tick. |
| The voice won't save or the launch is rejected.                           | The voice prompt is longer than 10,000 characters.                                               | Trim the prompt to 10,000 characters or fewer.                                                                                    |
| The reward split is rejected at launch.                                   | Adding the droid entry would go over the 7-recipient limit (6 reward recipients plus the droid). | Remove a reward recipient from your split, then launch again.                                                                     |
| An **Unusual positions** or **possible copy** banner appears.             | These are clanker.world warning tags, not droid errors.                                          | See [Warning Tags](/general/clanker.world-warning-tags).                                                                     |

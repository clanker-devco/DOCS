Other apps built on Clanker can deploy tokens for you. They use the Clanker SDK, the [deploy API](/general/token-deployments/v5-deployments) or the Clanker contracts directly.

## How it works

An interface can set deployment parameters that the clanker.world form and the @clanker bot don't offer, or set them in its own way. Check each interface's documentation for the options it supports.

## What an interface can customize

These include, but are not limited to:

* Creator reward splits
* Starting market cap
* Quote token pairs
* Liquidity curves, by placing multiple LP positions
* Vaults
* Airdrops
* Creator buy (dev buy)

Vaults, airdrops and custom liquidity positions apply to v4 tokens. See [v4 Deployments](/general/token-deployments/v4-deployments).

Other apps built on Clanker can deploy tokens for you. They use the Clanker SDK, the Clanker API (see [API Deployments](/general/token-deployments/v5-deployments)) or the Clanker contracts directly.

## How it works

An interface can set deployment parameters that the clanker.world form and the @clanker bot don't offer, or set them in its own way. Check each interface's documentation for the options it supports.

## What an interface can customize

These include, but are not limited to:

* Creator reward splits
* Creator buy (dev buy)

For v4 tokens, an interface can also set:

* Starting market cap
* Pair token (see [Supported Quote Tokens](/references/supported-quote-tokens))
* Liquidity curves, by placing multiple LP positions
* Vaults
* Airdrops

A v5 token always has a 1 billion supply in one pool paired with one of its chain's registered pair tokens, with a starting price set by the factory. See [Supported Quote Tokens](/references/supported-quote-tokens). See [API Deployments](/general/token-deployments/v5-deployments) for the v5 fields and [v4 Deployments](/general/token-deployments/v4-deployments) for v4.
